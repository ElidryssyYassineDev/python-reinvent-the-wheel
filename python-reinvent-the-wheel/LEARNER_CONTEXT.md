## Learning Preferences

My preferred methodology:

1. Understand the concept before implementing it.
2. Start with prerequisites.
3. Progress through small, meaningful milestones.
4. Implement exercises independently.
5. Receive hints before complete solutions.
6. Submit code for professional review.
7. Consolidate knowledge through active recall and testing.

I dislike excessive theoretical dumps and implementations that I cannot explain.

I prefer a mentor-style approach where I am actively involved in solving problems.
